Project 1: Painting Palette Drawing

This project is an exploration of digital mark-making by making a paint template where the code becomes both the brush and the canvas. I used keypresses to name the different brushes so that everyone could use them to interact. In addition, the canvas is changed to white or black so that everyone can interact according to their preferences. The difficulty I encountered was to choose a color that could work stably on the two colors of the background. For me, this is a success because of its convenience and fun, being able to create a work from itself and save it. I really like this Painting palette drawing because of its unlimited interaction and creativity.

How to Use it

Click and drag the mouse to use brushes:

1 = teal brush

2 = triangle brush

3 = green roof brush

4 = yellow shade brush

5 = bubble purple pink brush

6: eraser

n = change black or white Canvas

x = reset Canvas

p = print Canvas
